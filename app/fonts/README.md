# Inter local

`inter-latin-variable.woff2` vem de `@fontsource-variable/inter@5.3.0`, arquivo `files/inter-latin-wght-normal.woff2`, sem conversão. É a família Inter variável, pesos 100–900, estilo normal, subconjunto latino usado pelo layout.

O layout usa `next/font/local` para servir a fonte pela própria aplicação e permitir build sem consulta ao Google Fonts. Manter o arquivo e a licença ao atualizar; não substituir por uma fonte de fallback para fazer o build passar.
